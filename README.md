# TaskTerminal v1.0 — Kotlin Style Task Manager

Полноценное консольное приложение (с веб-интерфейсом в стиле терминала), разработанное в соответствии с требованиями учебного проекта. Приложение демонстрирует структурированную архитектуру уровня «новичок» (Data + Repository + Menu).

## 🚀 Функционал

- **Создание задач**: Автоматическая генерация ID, выбор приоритета (1–5).
- **Просмотр**: Отображение задач в виде таблицы с подсветкой выполненных пунктов.
- **Поиск**: Гибкая фильтрация по названию, приоритету и статусу выполнения.
- **Редактирование**: Изменение любых полей задачи (пропуск поля оставляет старое значение).
- **Удаление**: Удаление по ID с подтверждением (защита от случайных действий).
- **Сортировка**: По дате, приоритету или названию (в обоих направлениях).
- **Импорт/Экспорт**: Сохранение и загрузка базы задач в формате JSON.
- **Пакетные действия**: Возможность отметить выполненными или удалить несколько выбранных задач сразу.

## 🏗 Архитектура

Приложение разделено на четкие слои:
1. **Data layer (`types.ts` / `Task` class)**: Описание модели данных.
2. **Repository (`repository.ts` / `TaskRepository`)**: Логика обработки данных (CRUD, поиск, сортировка).
3. **Menu/Controller (`App.tsx` / `MenuController`)**: Интерфейс взаимодействия с пользователем.

## 🛠 Стек технологий

- **Frontend**: React 19, Vite.
- **Styling**: Tailwind CSS (дизайн "Professional Polish").
- **Animation**: Framer Motion.
- **Icons**: Lucide React.
- **Logic**: TypeScript (строгая типизация).

## 📄 Исходный код Kotlin

В корне проекта также находится файл `TaskManager.kt`, содержащий чистую реализацию данного функционала на языке Kotlin для использования в JVM-окружении.
